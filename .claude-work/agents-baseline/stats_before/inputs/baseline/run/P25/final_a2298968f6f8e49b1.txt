The claim is $\sum_{i=0}^{n-1}(2i+1)=n^2$ for all $n\in\mathbb N$. It is stated two ways:

- **Recursive:** `sumOdd 0 = 0` and `sumOdd (n+1) = sumOdd n + (2n+1)`. The theorem is `SumOdd.sumOdd_eq_sq : sumOdd n = n ^ 2`.
- **As a list sum:** `SumOdd.sum_first_odds : ((List.range n).map (fun i => 2*i+1)).sum = n ^ 2`. This is the plain sum $1+3+\dots+(2n-1)$.

**Proof:** induction on $n$.
- Base case: $0 = 0^2$, closed by `rfl`.
- Step: after the induction hypothesis, the goal is $n^2+(2n+1)=(n+1)^2$. This is the lemma `sq_add_odd`: expand both squares with `simp only [Nat.pow_two, Nat.add_mul, Nat.mul_add, …]`, then `omega` finishes, treating $n\cdot n$ as an atom.
- A second proof, `sumOdd_eq_sq'`, does the step with `grind` instead.
- `sumOdd_eq_list` shows the two forms are equal.

My first attempt at the step (`rw [Nat.pow_two, …]; omega`) failed and I replaced it; the final file has no errors.
