Every line is within 42 characters. The longest is line 2 of cue 2, at 32.

Translation choices:
- **"Não toques nisso!"** uses the informal *tu*, which is the usual choice for a direct, urgent line in pt-PT. If the speaker should be formal (*você*), it becomes "Não toque nisso!".
- **"temos de"** is the European Portuguese form; "temos que" is Brazilian.
- **Line break in cue 2:** I broke the line after the comma so each line reads as one unit of meaning.
- **Cue 1:** it's short, so I kept it on one line.
