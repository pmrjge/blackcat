**What it converts:**
- A 10-digit number is read as seconds, with an optional fraction of up to 9 digits; fractions are cut to microseconds, not rounded.
- A 13-digit number is read as milliseconds.
- Output is ISO-8601 with a `Z` suffix. Microseconds appear only when they aren't zero.
- A number is converted only if it isn't touching other digits or a decimal point. Version strings, 9-, 11- or 17-digit IDs and a trailing `1700000000.` are left as they are.

**What it doesn't convert:** a 10-digit window only covers dates from 2001-09-09 to 2286-11-20, so seconds outside that range are left alone. The tool takes no options beyond `--help`, and line endings are kept as they were.

**Setup:** Python 3.14 (`requires-python >=3.14`, set by uv's default). Ruff, pyright and pytest are dev dependencies inside the project, so nothing was installed globally. pyright uses the Node already on the machine; nothing was downloaded for it. Each check above was run with `uv run`.
