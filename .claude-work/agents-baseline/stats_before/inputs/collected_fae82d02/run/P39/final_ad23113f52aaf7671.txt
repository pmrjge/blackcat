- `qparse.py` is the scratch parser fixture. `QPARSE_SEED_BUG=1` turns on the seeded crash: an unchecked read of the second hex digit of a truncated `%X` at the end of a string.
- `test_fuzz.py` is a Hypothesis stateful fuzz target (`RuleBasedStateMachine`). It uses `derandomize=True`, `database=None` and 2000 examples, so it is deterministic.
  - It has two rules. `add_encoded` appends a `quote_plus`-encoded key/value pair, and `add_raw` appends junk with malformed escapes, `#`, `?` and `&`.
  - One invariant says the parser never raises and always returns string pairs. The other says that while the query is built only from encoded pairs, the parsed result equals the model.
- `test_snapshot.py` plus `snapshot_parse.json` is the snapshot test. It compares the parser output for 7 query strings against the committed JSON file. The cases cover the empty string, `+`, UTF-8 percent escapes, truncated `%` and `%4`, an invalid `%zz`, empty segments, a `#` fragment and an invalid byte `%ff`.
- `run.sh` runs `uv run --no-project --with hypothesis --with pytest pytest`. The dependencies are project-local and nothing was installed globally.
