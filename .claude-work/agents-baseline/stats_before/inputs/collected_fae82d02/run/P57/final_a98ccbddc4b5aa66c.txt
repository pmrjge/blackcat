How the pipeline works (details and risks are in plan.md):
- **Retopo:** voxel remesh at bbox-diagonal/250 to get a clean closed mesh, then QuadriFlow at 5000 faces, then shrinkwrap back onto the sculpt.
- **UVs:** Smart UV Project, then one uniform rescale `s = (512/2048)·sqrt(A_world/A_uv)` so the density is exactly 512 px/m. Islands are then packed with `scale=False` so packing can't change it. At this density one 2048 tile covers 4 m × 4 m, so it holds about 10–12 m² of surface; the script logs the UV area it needs and whether it fits.
- **Bake:** Cycles, selected-to-active, cage set from the bbox size.
  - Normal map: tangent space, OpenGL (+Y), 16-bit PNG.
  - AO map: 8-bit PNG, 128 samples by default.
- **Output:** a .blend and an FBX are saved next to the maps in `out/`.
- **Input:** `--demo` builds a stand-in sculpt (about 330k tris, 1.0 × 0.8 × 1.3 m); `--high <name>` uses a real one from an open .blend.
