# quantum-computing — math essentials (reference)
Read when you need the linear-algebra and measurement formalism (states, channels, Pauli algebra). Parent: `quantum-computing` SKILL.md.

## 1. Mathematical essentials
- States:
  - Pure states are unit vectors in (ℂ²)^⊗n up to global phase. Mixed states are density matrices:
    ρ ⪰ 0, tr ρ = 1, with purity tr ρ² ∈ [1/d, 1].
  - Qubit on the Bloch sphere: ρ = ½(I + r·σ) with |r| ≤ 1. R_n(θ) = exp(−iθ n·σ/2) rotates r by θ
    about n; SU(2) → SO(3) is 2:1, so a 2π rotation gives −I.
- Measurement:
  - Projective {Π_k}: p(k) = tr(Π_kρ), with post-measurement state Π_kρΠ_k/p(k). POVMs are E_k ⪰ 0
    with ∑E_k = I.
  - For a Pauli P over N shots, the standard error of ⟨P⟩ is √((1−⟨P⟩²)/N).
- Channels (CPTP maps):
  - Kraus form ∑K_k†K_k = I. Choi: CP ⇔ Choi ⪰ 0; TP ⇔ the partial trace of the Choi matrix over the
    output is I. Stinespring dilation.
  - Standard channels: depolarizing, amplitude damping (T1), dephasing (T2). Pauli twirling turns any
    channel into a Pauli channel.
- Ordering convention, the #1 cross-framework bug:
  - Qiskit is little-endian: qubit 0 is the rightmost character of a label or bitstring and the least
    significant index. `Statevector.from_label("01")` has qubit 0 in |1⟩, i.e. basis index 1.
  - Cirq and PennyLane treat the first listed wire as most significant, so the same circuit gives
    bit-reversed vectors across frameworks.
- Partial trace and Schmidt decomposition: reshape a pure state to d_A × d_B; its singular values are
  the Schmidt coefficients.
- Entanglement measures:
  - Entanglement entropy S(ρ_A) = −tr ρ_A log ρ_A, equal for complementary parts of a pure state.
  - Mutual information I(A:B) = S_A + S_B − S_AB. Concurrence for two qubits.
  - PPT/negativity (Peres–Horodecki): PPT is necessary for separability, and sufficient for 2×2 and
    2×3 systems.
- Distances:
  - Qiskit's `state_fidelity` uses the squared convention F = (tr√(√ρσ√ρ))², so pure states give
    |⟨ψ|φ⟩|².
  - Trace distance D = ½‖ρ−σ‖₁, with 1 − √F ≤ D ≤ √(1−F).
  - Average gate fidelity F_avg = (d·F_pro + 1)/(d + 1). A single-qubit depolarizing channel with
    p = 0.1 gives F_pro = 0.925 and F_avg = 0.95.
- Cliffords and universality:
  - The Clifford group, generated by H, S and CNOT, normalizes the Pauli group. Gottesman–Knill:
    stabilizer circuits are classically simulable (Aaronson–Gottesman tableaux, quant-ph/0406196).
  - Clifford+T is universal. Solovay–Kitaev gives polylog(1/ε) gate counts; arbitrary rotations cost
    O(log 1/ε) T gates with modern synthesis.
